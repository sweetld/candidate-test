### Bug #7: Priority Sorting Reversed

## Features Implemented

### Feature #1: Accessibility Improvements

**Details:**
Added role and aria attributes.
Changed buttons to groups of buttons where applicable.
Not needed where inputs are already labelled by associated labels (<label htmlFor=...).
Enhance accessibility for screen readers.
Small changes to colours for visually impaired users.

**Implementation Approach:**
Used ChatGPT to identify WCAG compliance issues.
Generated a Lighthouse report to identify accessibility issues, and test fixes.

### Feature #2: Enums for Task Status and Priority

**Details:**
Changed implementation of task status and priority from string literals to TypeScript enums.
This improves type safety and reduces the risk of typos in status and priority values.

**Implementation Approach:**
Implemented TypeScript enums for task status and priority in tasks.ts file, and then updated all 
references throughout the codebase to use the enums instead of string literals.


### Feature #3: Task Analytics Dashboard

**Details:**
As per the requirements, created a dashboard component that displays analytics about tasks.
Metrics Cards showing:
- Total tasks
- Completion rate (%)
- Overdue tasks count
- Tasks by status breakdown

Task Status Distribution (Donut/Pie Chart) showing breakdown of todo/in-progress/done,
the counts and percentages for each status.

Support clickable segments to change filtering the main task list

**Implementation Approach:**
Added new component TaskAnalyticsDashboard that fetches task data and computes the required metrics.
Used Recharts library to create the donut chart for task status distribution.
Replaced the original Statistics Dashboard in the app.ts page with the new Analytics Dashboard in the TaskAnalyticsDashboard component.
Moved the stats from the app.ts to the TaskAnalyticsDashboard component.

### Feature #4: Made Search Case-Insensitive

**Details:**
The search functionality was case sensitive, which could lead to missed results.


**Implementation Approach:**
Updated the search logic to convert both the search term and task titles/descriptions to lowercase before comparison


### Feature #5: Improved Performance of Task Filtering and Sorting

**Details:**
The filtering and sorting logic was being executed on every render, which could lead to performance issues with larger task lists.

**Implementation Approach:**
Switched to using useMemo to memoize the filtered and sorted task list, so that the computation is only redone when the relevant dependencies change (tasks, filterStatus, sortBy, sortDirection, searchTerm).


### Feature #6: Added Some Useful NPM Scripts

**Details:**
Added some useful npm scripts for testing, linting, formatting, type checking, and e2e testing.

**Implementation Approach:**
Added the following scripts to package.json:

    "test:watch": "nx test --watch",
    "coverage": "vitest run --coverage",
    "lint": "nx lint",
    "format": "prettier --write .",
    "format:check": "prettier --check .",
    "typecheck": "tsc --noEmit -p tsconfig.json",
    "e2e": "nx e2e"
